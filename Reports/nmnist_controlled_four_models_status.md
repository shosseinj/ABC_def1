# Controlled local four-model N-MNIST comparison

Status: IN PROGRESS. The published Table 1 and Table 2 values remain reference numbers and are not the controlled comparison.

The controlled experiment trains the local custom SNN plus the paper repository's ConvNet (`SimpleNet_v2`), Spiking ResNet18, and VGGSNN on the same official N-MNIST train/test partition. For each representation separately, all models use the same equal-event-count `T=10` cache, seed 42, stratified 55,000/5,000 train/validation split, Adam with learning rate 0.001 and weight decay 0.0001, batch size 64, up to 15 epochs, and best validation accuracy/loss checkpoint selection. Binary and Integer are distinct training campaigns. The existing custom checkpoints qualify under this frozen recipe; the three reference architectures are being trained locally with the same recipe. A 95% full-test clean-accuracy gate prevents undertrained models from entering the attack comparison.

After training, a single deterministic manifest selects the first 1,000 official test examples correctly classified by all four models. Every model receives the same sample IDs under each budget. The official-source PIL-PGD adapter, frozen representation, budget definitions, iteration counts, and independent raw-event reconstruction auditor are shared. This is a **new controlled local comparison**, not a replication of the paper's unavailable N-MNIST checkpoints or unspecified training details. The official source's hard-coded B0 penalty of 5 is used consistently for all four models; this differs from the paper's general-text value of 10 and is disclosed.

Current stage: ConvNet Binary training has started. No controlled four-model ASR has been validated yet. The existing `readme_jafar.md` paper-reference tables must not be relabeled as controlled results. Runner: `scripts/run_nmnist_controlled_four_models.ps1`. Without flags it runs the two most diagnostic budgets (`B∞=1`, `B0=200`) for Binary and Integer after training. `-FullBudgets` runs all paper-table budgets. Every unit resumes from its smallest missing checkpoint/partial result and skips hash-verified completed work.
